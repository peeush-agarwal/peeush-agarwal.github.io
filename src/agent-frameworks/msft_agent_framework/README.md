# Microsoft Agent Framework

This repository contains a collection of tutorials, code examples, and best practices for building AI agents using Microsoft's Agent Framework. The framework provides tools and libraries to create intelligent agents that can interact with users, process natural language, and perform various tasks.

## Setup dev environment

1. `uv init --bare`
1. `uv add agent-framework python-dotenv --prerelease=allow`

## OpenAI Agents

1. `uv run open_ai/openai_chat_completion_agent.py`
1. `uv run open_ai/openai_responses_agent.py`
